# Feedback and contributions / フィードバック

## English

Use this repository's **Issues** tab for bug reports and feature requests. Include the app version, device, Android/WebView versions, reproduction steps and a minimal sketch. Remove private information from attachments.

Edit:RiN is free software distributed under the GNU General Public License, version 3 or later. See [LICENSE](LICENSE) for the terms of modification and redistribution. Please discuss a proposed code contribution in Issues before preparing it. Third-party components retain their own licenses.

## 日本語

不具合・機能提案の連絡はこのリポジトリの **Issues** タブへお願いします。アプリのバージョン、端末名、Android・WebViewのバージョン、再現手順と最小限の作品コードを記載してください。添付物の個人情報は削除してください。

Edit:RiNはGNU General Public Licenseのバージョン3以降で配布するフリーソフトウェアです。改変・再配布の条件は[LICENSE](LICENSE)を確認してください。コードの提供を考えている方は、着手前にIssuesでご相談ください。第三者のコンポーネントには各ライセンスが適用されます。
