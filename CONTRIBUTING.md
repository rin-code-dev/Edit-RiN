# Feedback and contributions / フィードバック

## English

Use this repository's **Issues** tab for bug reports, feature requests and permission requests. Include the app version, device, Android/WebView versions, reproduction steps and a minimal sketch. Remove private information from attachments.

This is a source-available project, not an unrestricted open-source license. Before modifying, reusing or distributing project material, contact rin-code-dev and obtain explicit written permission as described in [LICENSE](LICENSE). Please discuss a proposed code contribution before preparing it. Third-party components retain their own licenses.

## 日本語

不具合・機能提案・利用許可の連絡は、このリポジトリの **Issues** タブへお願いします。アプリのバージョン、端末名、Android・WebViewのバージョン、再現手順と最小限の作品コードを記載してください。添付物の個人情報は削除してください。

本プロジェクトはソース公開型であり、無制限に利用できるオープンソースライセンスではありません。改変・転用・再配布の前に、[LICENSE](LICENSE)に従いrin-code-devへ連絡し、明示的な許可を得てください。コードの提供も着手前にご相談ください。第三者のコンポーネントには各ライセンスが適用されます。
