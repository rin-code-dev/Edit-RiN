サンプルを開き、コピーして編集するOpen a sample and make an editable copy

#

完成したサンプルの動きを確かめてから、自分の作品として編集できます。Explore a finished sample, then make your own editable work.

開く場所WHERE

画面上部の作品名 → 作品一覧 → サンプルWork title at the top → work picker → Samples

操作手順STEPS

  1. Paletteなどのサンプルを選び、プレビューを操作します。Select a sample such as Palette and interact with its preview.
  2. コードを変更するときは「コピーして編集」を押します。Choose Copy to edit when you want to change its code.
  3. 名前を入力して作成し、「自分の作品」に切り替わったことを確認します。Name the copy and check that it appears under My works.

操作後RESULT原本を残したまま、独立したコピーを編集できます。You can edit an independent copy while keeping the original.

条件・確認することCONDITIONS & CHECKS

サンプル原本は読み取り専用です。コードの選択・コピー、折りたたみ、利用できるパラメーターの試用は可能です。Sample originals are read-only. You can select and copy text, fold blocks, and try available parameters.

新しい作品を作るCreate a work

#

テンプレートのコードと実行設定を使って、新しい作品を作成します。Start with code and runtime settings supplied by a template.

開く場所WHERE

作品一覧 → ＋Work picker → +

操作手順STEPS

  1. 作品名とプレビュー比率を指定します。Choose a name and preview ratio.
  2. 2D、アニメーション、マウス／タッチなどのテンプレートを選びます。Select a template such as 2D, Animation, or Mouse / Touch.
  3. 「作成」を押し、コードを編集して実行します。Choose Create, edit the code, and run it.

操作後RESULT選んだテンプレートを使った新しい作品ができます。A new work is created from the selected template.

条件・確認することCONDITIONS & CHECKS

新規作成では現在の作品のコードをコピーしません。既存作品を元にする場合は「複製」を使います。Creating a work does not copy the currently open code. Use Duplicate to start from an existing user work.

自作テンプレートを保存・再利用するSave and reuse your templates

#

繰り返し使うコード・素材・実行設定を、新規作成の出発点にできます。Reuse code, assets, and runtime settings as a starting point.

開く場所WHERE

作品メニュー → テンプレート・ピン・タグ・名前・複製 → テンプレートとして保存Work menu → Templates, pin, tags, rename, duplicate → Save as template

操作手順STEPS

  1. 元にする作品を開き、補助ファイルと素材も確認します。Open the work and check its supporting files and assets.
  2. テンプレートとして保存し、名前を付けます。Save it as a template and give it a name.
  3. 新規作成で「自作テンプレート」を選びます。Select My templates when creating a new work.

操作後RESULTテンプレートの内容を引き継いだ別の作品を作成できます。A separate work inherits the template contents.

条件・確認することCONDITIONS & CHECKS

作品メニューの「テンプレート管理」では検索・名前変更・更新ができます。削除しても、そのテンプレートから作成済みの作品には影響しません。Use Manage templates in the work menu to search, rename, or update templates. Deleting one does not affect works already created from it.

操作手順STEPS

編集キーで数値を調整するAdjust numbers with the accessory scrubber

#

カーソル位置の数値を、編集キーのドラッグ操作で変更できます。Adjust the number at the caret using the accessory scrubber.

開く場所WHERE

エディターで数値にカーソルを置く → 編集キーの数値調整Place the caret on a number → numeric scrubber in accessory keys

操作手順STEPS

  1. コード内の数値にカーソルを置き、編集キーに数値調整が表示されることを確認します。Place the caret on a numeric literal and locate the scrubber in the accessory bar.
  2. 編集キーの数値調整を左右にドラッグします。上下方向では調整の刻みを変えられます。Drag the accessory scrubber left or right. Dragging vertically changes its adjustment step.

読み取り専用のサンプルはコピーしてから編集します。文字列の中の数字は数値リテラルとは扱いが異なります。Copy a read-only sample before editing. Digits inside strings are not numeric literals.

手動実行・Auto-Run・一時停止Run changes, Auto-Run, and pause

#

コードの再実行と、描画の一時停止を使い分けます。Choose when to rerun code and when to pause drawing.

開く場所WHERE

実行操作・AUTOボタン／設定 → 画面と実行 → 作品切替時に自動実行Run controls & AUTO button / Settings → Display and run → Run when switching works

操作手順STEPS

  1. コードを変更し、手動の場合は「変更を実行」を押します。Edit the code and choose Run changes when running manually.
  2. AUTO（Auto-Run）を有効にすると入力が止まった後に再実行し、「作品切替時に自動実行」では別の作品を開いたときに自動で実行します。Enable AUTO (Auto-Run) to rerun after typing pauses; enable Run when switching works to run automatically when opening another work.
  3. アニメーションを止めたいときは一時停止し、再開します。Use Pause and Resume to inspect an animation.

操作後RESULT再実行では最新のコードを読み込み、一時停止では描画の進行を止めます。Rerunning loads the latest code; pausing stops drawing progression.

条件・確認することCONDITIONS & CHECKS

通常の再実行や素材の変更ではプレビューを再読み込みするため、音声やアニメーションが最初から始まる場合があります。一時停止の対象はp5描画・アニメーションフレーム・CSSアニメーションで、通常のタイマーや無関係な非同期処理は続きます。Normal reruns and asset changes reload the preview and may restart audio or animation. Pause covers p5 drawing, animation frames, and CSS animations; plain timers and unrelated asynchronous tasks continue.
