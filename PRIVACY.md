# Privacy / プライバシー

## 日本語

Edit:KIROは、作品・設定・インポートしたフォントを端末に保存します。
アプリ独自のアカウント登録、広告SDK、アクセス解析SDK、開発者への作品送信機能はありません。

実行した作品が外部の画像・データなどを読み込むと、その接続先に通信します。
通信内容は作品のコードと外部サービスによって異なります。

スクリーンショットと録画は端末に保存します。Android 10以降ではPictures/EditKIRO
またはMovies/EditKIROへ保存し、古いAndroidではアプリ専用の外部ストレージへ保存します。
ファイルの読み込みやバックアップの書き出し先はAndroidのファイル選択画面で選びます。

Androidのシステムバックアップが有効な場合、OSや端末の設定に従ってアプリデータが
バックアップされる場合があります。これは開発者独自のクラウド保存機能ではありません。
お問い合わせは公開リポジトリのGitHub Issuesへお願いします。

## English

Edit:KIRO stores works, preferences and imported fonts on the device. It has no
app account registration, advertising SDK, analytics SDK or feature that uploads
works to the developer.

Sketches can contact external services when their code loads images or data.
Those requests depend on the sketch and the destination service.

Screenshots and recordings are saved locally: Pictures/EditKIRO or Movies/EditKIRO
on Android 10+, and app-specific external storage on older versions. Android's
file picker is used to choose imported files and backup destinations.

Android system backup may back up application data according to OS and device
settings. This is separate from any developer-operated service. Please use the
public repository's GitHub Issues for questions.
