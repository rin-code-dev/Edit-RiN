# Edit:KIRO Icon System

The current UI icon set consists of original Edit:KIRO artwork drawn on a 24 x 24 grid.
The launcher icon uses the approved code-mark motif on a pale blue background.

## Current UI mapping
- 24 x 24 viewport and 1.65-unit rounded stroke for UI controls
- Geometric silhouettes with consistent spacing at 19–22 dp display sizes
- Separate, purpose-drawn symbols for reload, history and canvas orientation
- Shared code-mark motif for adaptive, monochrome and legacy launcher icons
- Source SVG files are retained in artwork/icons for future editing

The Android resources are VectorDrawable conversions of the approved original SVG set.

Both used and reserved icon resources use the same original geometry.
